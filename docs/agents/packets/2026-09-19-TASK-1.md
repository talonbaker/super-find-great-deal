## Goal

The hider is absorbed in a job that needs eyes and hands: every object has a colour AND a shape,
and the bins ask for only one of the two. Sorting by colour, a red ball and a red cube go together;
sorting by shape, the red ball goes with the blue ball. The interruption costs the object in your
hands and the rhythm you had. Score accrues visibly, so being found late is legible.

## Build (authored in `TaskRoom.tscn`)

- **Objects**: 18 sortables in a **supply crate** (an open box, authored transforms): 3 colours
  (red, blue, yellow) × 3 shapes (cube 0.15 m, ball r 0.08 m, can r 0.05 m h 0.14 m) × 2 each.
  Each a `NetworkedProp` + `Interactable` + `Carryable` with SFX-1's material tag set by shape
  (cube = Wood, ball = Produce, can = Tin — so they sound different too). One `SortItem` component
  on each carrying `Colour` and `Shape` enums (authored in the scene; not on the wire — every peer
  has the scene). Deterministic node names (`Sort_000` …) for `AdoptAuthoredProps`.
- **Three bins** along the wall within `BurstRadiusM` of the door: open boxes, each with an
  `Area3D` volume and a front **label plate** (`Label3D`, same construction as CLOCK-1's clock and
  HOLD-1's board). Bins never move.
- **The rule of the round** is derived, not sent: `SortRule.For(round) = round % 2 == 1 ? Colour :
  Shape` (round 1 sorts by colour, round 2 by shape, …). Engine-free, unit-tested. Under `Colour`
  the plates read RED / BLUE / YELLOW and the plate tints match; under `Shape` they read CUBE /
  BALL / CAN with a small unshaded icon mesh of the shape above the word. Plates re-label on the
  reset edge for the new round.
- **Scoring (server, engine-free rule + one adapter)**: an object counts when it has been
  `Resting` inside a bin's `Area3D` for `SettleSec` (0.5) and the bin matches the rule
  (`SortRule.Matches(rule, item, bin)`). Each object counts **once** (a set of counted ids);
  taking it out again subtracts nothing. Correct → `SortsCompleted` += 1, the bin plate flashes,
  a short positive tick plays on every peer (append `Sfx.SortGood` after SFX-1's ordinals; state
  the number). Wrong bin → a buzz (`Sfx.SortBad`) on every peer, nothing subtracted, the object
  stays where it is until the player moves it. No penalty; the cost is time.
- **Rename** ROUND-1's `TowersCompleted` fact/wire/HUD text to `SortsCompleted` in the round files
  (engine-free, tests updated; the wire's byte layout is unchanged — same slot, new name). At
  `Found(tick)` ROUND-1 freezes the count (`SortsAtFound`); you do nothing special at the burst
  except let DOOR-1's forced drop and impulse happen. Verify one capture shows an object knocked
  out of the player's hands or a bin's mouth.
- HUD: "SORTED 7 · BY COLOUR" on the hider's strip from the wire (the rule is derived from
  `Round`, so no new field).
- **Reset**: on `ResetRequested`, objects return to their crate transforms, the counted set clears,
  plates re-label for the next round's rule.
