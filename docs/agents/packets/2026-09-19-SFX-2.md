## Why this is a gameplay bug, not polish

The seeker's only remote sense of the hider is what they can hear through the wall. Today a Loose
prop on a non-authority peer is a frozen kinematic body: Godot reports it no contact, so a can the
hider knocks off a shelf is silent on the seeker's client. And a throw and a set-down arrive as the
same state change, so a remote peer plays the throw whoosh for a careful place and never hears the
material's settle tick. Both are the same fix: the server, which is the only peer that sees every
contact, says what happened.

## Build

- **Impact event on the wire (server → all, unreliable-ish is fine, small).** When the server's
  `Carryable.OnBodyEntered` accepts a contact (past the speed threshold and cooldown, after the
  first-come de-dup), it emits `PropImpact(propId, intensityByte, position)` through
  `PropManager` on the prop channel (or a new small channel — say which and why; keep it out of
  the reliable ordered stream the state RPC uses, so a burst of forty impacts cannot delay a
  grab). Every client, **including the host**, plays the impact from this event and no longer from
  its own local `body_entered` — one path, one sound, so the host cannot hear a hit twice.
  Position is the prop's authored/replicated position at the event; a client plays it at its own
  copy of the prop if it has one, else at the sent position.
- **Rate limit at the source**: per prop the existing 0.4 s cooldown; globally the server sends at
  most `MaxImpactsPerTick` (4) per physics tick, keeping the loudest (highest intensity) — this is
  the "source-side limiting" SFX-1 named; report the steal rate on the 40-prop drop with it on.
- **Release reason on the state change**: `ApplyPropState` (or the `PropState` it carries) gains
  one byte `Release { None, Dropped, Placed, Thrown }` set by the server's funnel (CARRY-1's
  `RequestPlace` → Placed; throw → Thrown; a plain let-go or the burst's forced drop → Dropped).
  `NetworkedProp` fires `ActorEvent.Placed` / `Thrown` / `Dropped` from that byte on every peer, so
  the material's settle tick and the whoosh are heard by everyone for the right reason. Late-join
  snapshot: the byte is `None` (nothing to play).
- `ProtocolVersion` stays at **16** (SFX-1 bumped for this wave; do not bump again — say so).
- Dedicated server never plays anything (existing `ActorFx` early-out); the windowed host plays
  from the event like any client.
