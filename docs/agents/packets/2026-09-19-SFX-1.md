## Goal

Picking things up and bumping them into each other feels tactile and alive. A can is tin, a cereal
box is cardboard with something shifting inside, produce is soft and organic. Nothing is silent,
nothing is the same generic clink.

## Build

### Material tag and profiles (data, not code paths)

  It does **not** go on the wire: sound plays client-locally from replicated prop state on every

### Recipes (append to `Sfx`, ordinals are a `.tres` contract — never renumber)

Twelve new one-shots in `SfxLab`, one paragraph of synthesis notes each in the handoff:

| Event | Tin | Cardboard | Produce |
|---|---|---|---|
| PickedUp | `TinPick` — short bright clink, 2–3 inharmonic partials, ring 0.15 s | `CardPick` — 0.2 s band-passed noise rustle with a 20 ms attack, no tone | `ProducePick` — dull soft tap, one damped low sine, 60 ms |
| Impact | `TinClank` — inharmonic partials (e.g. 1 : 2.76 : 5.4), ring 0.4 s, a noise burst front; at high intensity add a buzz layer | `CardThud` — hollow "bop": low damped sine + short noise, 0.12 s, plus a 0.15 s rustle tail; never rings | `ProduceThump` — low damped sine + 30 ms noise, no ring, 0.1 s |
| Placed | `TinTick` — rim tick, 40 ms | `CardSettle` — papery settle, 80 ms | `ProducePlop` — soft plop, 70 ms |
| Thrown | `Whoosh` — one shared brief noise sweep, 0.12 s | same | same |

Rules:
- **Intensity from hit speed.** `Carryable.OnBodyEntered` computes relative speed at contact (own
  `LinearVelocity` minus the other body's when it is a `RigidBody3D`, else own) and passes it as
  `intensity` normalized over `[ThunkSpeedThreshold, 8 m/s]`. Profiles use `IntensityVolumeBoostDb`
  and a new `IntensityPitchRange` (pitch drops slightly for heavy hits on cardboard/produce, rises
  for tin). The 0.4 s per-body cooldown stays.
- **Prop-on-prop hits fire once.** When both bodies are `Carryable`, only the one with the lower
  instance id (or the faster one — pick one rule, state it) plays; the other suppresses for that
  contact. Prove it in the smoke: two props colliding produce one `Impact` fire, not two.
- **Held props** stay silent on contact (existing `IsHeld` gate) except the holder's own soft
  `Bump` when they scrape something at > 1 m/s — implement only if it falls out of the same code
  path in under 20 lines; otherwise note it as follow-up.
- Everything positional through `SfxLab.PlayStream3D`. No new bus. Dedicated server never plays
  (existing `ActorFx` early-out).
